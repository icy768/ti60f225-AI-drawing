每一阶段均从上一步的权重开始新的 Adam 微调，未恢复上一步 Adam 动量；“步数”是优化器更新次数，不是 epoch。每步 batch=4、256×256 随机内容裁切，按三种风格轮流训练。v6 的 2400 步对应每种风格 800 次更新。训练 seed=20261004。v3 沿用其原脚本 seed。

v4/v5/v6 的每 600 步权重均单独保存，可回退；旧 `art_styles_c24_hwqat` 和原硬件权重未覆盖。v6 保存了初始化权重哈希、代码快照、优化器与随机数状态；当前脚本的 `--init` 是权重微调入口，并不承诺中断后逐 batch 精确恢复。

日志里的 `gram/content/prior` 是各诊断项原值，不是加权后的贡献。v5/v6 的 `prior` 字段沿用旧弱空间先验诊断；v6 实际优化使用 `art_spatial_priors.py` 的新目标，精确损失组合以本次 `source_snapshot/train_art_styles_v4.py` 为准。不要仅根据不同阶段的总 loss 大小给画质排序。

## 指标的含义与局限

`comparison_200.json` 中同一风格的 v3/v6 使用完全相同的 200 张内容照片和 VGA 中心裁切口径。指标是每张图先计算、再对 200 图求均值。

- `chroma_range_255`：像素 RGB 最大最小值的平均差，范围 0–255。它不是 HSV 饱和度，也不是风格相似度分数。
- `paper_like_fraction`：亮度 >=0.90 且 RGB 极差 <=0.08 的像素比例。只能反映纸白/亮部，不能证明具有艺术意义的留白构图。
- `dark_fraction`：亮度 <0.20 的比例，用于检查浓墨或暗部是否消失；越大不一定越好。
- `flat_neighbor_fraction`：水平和垂直相邻亮度差均 <0.01 的比例。用于观察平滑区增加，但模糊也能提高它。
- `gradient_mean_255`：水平、垂直相邻亮度差均值之和，区分边缘/纹理变化；噪声同样会提高它。
- `quantized_rgb_bins`：RGB 每通道按 32 个灰度值分桶后占据的桶数，最多 512；它不是实际输出只有这么多颜色。

没有用“输出相对原照片的 PSNR/SSIM 更高”证明风格更好，也没有将这些指标称为艺术识别率或与行业 SOTA 的比较。强风格本来就需要改变颜色和局部结构。

## 仍然存在的视觉问题

1. 梵高已经增强蓝黄关系和油彩纹理，但长程旋涡笔触、厚涂立体感与参考画仍有差距，部分区域仍有细颗粒和均匀纹理。
2. 浮世绘的颜色与轮廓更集中，但还没有全面达到参考木版画的大块纯色和稳定闭合墨线；部分自然纹理仍保留，暗部可能过重。
3. 水墨的色度下降、纸白和浓墨增多，但部分场景仍近似黑白插画或处理过的照片；书法性提按、自然飞白和有语义的留白尚未得到证明。
4. 这些仍是逐图结果。真实视频中的闪烁、场景变化、噪声放大、IN 跨帧统计和风格切换尚未验证。

因此将 v6 定位为**强风格浮点候选、供视觉审看和继续优化**，而不是最终比赛模型。继续训练应针对具体不足做消融，不按总步数或色度单指标自动宣布达标。

## 新模型部署状态

本次候选为 FP32，`qat=False`。训练冻结了旧激活观测器；checkpoint 中继承的激活量程已经失效，**不能直接导出作为新模型的正确量化参数**。

下一阶段需依次做新激活校准、实际整数 PTQ 误差检查、必要时硬件一致 QAT、逐层 RTL 对拍，再对带新权重和实际板级约束的工程综合/布局布线。最终还需要原始相机视频和板端唯一 frame_id 帧率验收。

所提供的显示屏照片已经单独处理并保存；它包含屏幕、透视、反射和二次拍摄过程，不能作为 SC431HAI 原始 RGB 帧或视频稳定性的替代证据。
