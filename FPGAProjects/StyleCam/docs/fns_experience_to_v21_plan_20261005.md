# Fast Neural Style 经验迁移到 StyleCam v21

日期：2026-10-05

## 审查状态（2026-10-05）

本计划的“离线 FNS 教师 + 固定 v6 学生 + QAT”方向可行，但原文起点已过期：v20 已经完成训练、整数导出和 24 图评估，不能再写成“只有训练中间文件”。本计划应从 v20 继续做单因素实验，不应直接跳入全量 FNS 教师蒸馏。

另外，`T_mix = α·T_fns + (1-α)·T_v19` 的逐像素线性混合不宜作为默认实现。两个教师的笔触位置、色块边界和亮度分布并不配准，像素平均会使梵高笔触变短、浮世绘颜色变灰。修订后的默认做法是：在 VGG/Gram、局部梯度、区域色彩统计和轮廓统计上混合教师信号；像素目标只在主体/边界掩码内低权重使用，并分别设定梵高和浮世绘的色彩对比门槛。

详细逐项审查见 `docs/fns_experience_to_v21_review_20261005.md`。

## 当前起点

当前最新的完整研究候选是浮点 `runs/art_styles_c24_v19_expanded_skill/student.pt` 与 INT8/QAT `runs/art_styles_c24_v20_qat900_soft1/student.pt`；整数合同为 `audits/v20_qat900_export/`，24 图评估为 `audits/v20_qat900_paired24/summary.json`。v20 仍不是板端候选，因为物理 Ti60/SC431HAI 尚未验证。

v19 仍固定 v6 推理图：`C=24, Fc=16, n_res=4, block=dw1, IN`，11,028 参数，640×480 输入输出，339,148,800 VGA 卷积 MAC。v19 已有 VGG 多层特征、Gram 风格统计、区域方向/轮廓、浮世绘块内变化、水墨纸白/浓墨、相机扰动和时间一致性监督。

v20 的 24 图 INT8 基线如下。PSNR/SSIM 是相对 v19 浮点艺术参考或自身 FP32 的工程诊断，不是赛题官方绝对阈值。

| 风格 | INT8 对 v10 参考 PSNR/SSIM | INT8 对自身 FP32 PSNR/SSIM | 当前主要缺口 |
|---|---:|---:|---|
| 梵高 | 26.43 dB / 0.897 | 22.65 dB / 0.847 | 中高频笔触仍弱，Skill 的长笔触和亮暗对比更强 |
| 浮世绘 | 28.22 dB / 0.899 | 24.81 dB / 0.849 | 块面和边界改善，但颜色仍比 Skill 暗、纯度不足 |
| 水墨 | 27.00 dB / 0.901 | 23.07 dB / 0.856 | INT8 比 FP32 更黑，干湿边缘仍不足 |

## 三部分经验怎样借鉴

### 1. 借鉴效果实现逻辑，不搬运重型推理图

外部网络的有效逻辑是：冻结 VGG 损失网络；用低层到高层的内容特征保护主体；用多层 Gram 统计学习颜色、纹理和共同模式；用 TV 抑制噪点；训练结束后只保留生成网络。

StyleCam 已经有 VGG/Gram 和内容损失，因此 v21 只新增一项：训练一个**离线高容量 Fast Neural Style 教师**，对真实 COCO 留出输入产生风格化目标，再把教师的像素、特征、梯度和区域统计蒸馏给当前 TinyStyleNet。VGG、Gram 和教师网络都不会进入 FPGA 推理图。

外部代码中的 9×9 卷积、普通 128 通道残差块和反射填充不能加入 v6 图。其 resize-conv 经验只能保留为训练参考；当前 TinyStyleNet 已经使用 nearest 上采样，边界问题用训练期反射边缘损失和边界掩码处理。

### 2. 借鉴赛题允许的算法方向，保持当前多风格切换能力

赛题允许 Fast Neural Style、简化 CycleGAN 或自设计微型 CNN。v21 仍使用一个三风格条件模型，而不是外部项目的三个独立部署模型：

- 共享卷积权重继续保持 v6；
- 三种风格继续通过 IN affine 行选择；
- 风格切换继续只改变风格索引和权重 bank；
- 不引入 VGG、Gram、光流、额外帧缓存或后处理算子；
- 训练增强只改变权重，不改变 13 层硬件图。

这样可以借鉴 Fast Neural Style 的训练质量，同时保留赛题要求的 FPGA 轻量化、实时切换和现有整数合同。

### 3. 借鉴风格表现，但给每种风格保留不同的保护目标

外部网络风格明显，不能只用一个统一风格权重模仿。v21 采用**特征空间混合教师目标**：

`S_mix = α·S_fns + (1-α)·S_v19`

其中 `S` 包含 VGG/Gram、局部梯度、区域色彩统计、方向统计和轮廓统计；`T_fns` 是离线 Fast Neural Style 教师，`T_v19` 是当前通过区域约束的教师。α 从 0.15 缓慢升到 0.35。默认不对两张不配准图像做全图逐像素平均；像素项仅在主体/边界掩码内低权重使用，避免平均掉笔触和色块。

三种风格的监督分别为：

- **梵高**：教师像素/多层特征 + 方向梯度一致性 + 按区域笔触连续性 + 源主体边缘保持。目标是让天空、道路、水面出现成组方向性纹理，而不是靠全局锐化制造噪声。
- **浮世绘**：教师色调/调色板 + 块内局部变化惩罚 + 块间边界梯度提升 + 深色轮廓保持。目标是同时得到平坦色块和清晰木刻轮廓，避免整体柔化。
- **水墨**：教师灰度/墨层 + 主体浓墨 + 背景纸白 + 边缘消散 + 干笔高频；QAT 阶段额外约束主体/背景比例，防止 INT8 把整幅图压黑。

## 具体实现阶段

### 阶段 A：构建合法的离线教师

不直接使用博客项目的未知授权权重。用工作区现有 `TransformerNet` 结构自行训练三个离线教师，训练数据只使用已记录来源和授权的开放艺术图；模型保存在 `runs/fns_teacher_cc0_20261005/`，并记录来源、哈希和配置。

教师结构可以采用外部项目的 32/64/128、5 个普通残差块、InstanceNorm 和 resize-conv 逻辑，但只用于 CUDA 训练/生成目标，不进入 FPGA。

训练损失：

```text
L_teacher = 0.20 L_content(VGG)
           + 1.00 L_gram(VGG, 4 layers)
           + 0.02 L_TV
           + 0.10 L_edge-preserve
```

教师先在 256×256 crop 上训练，再固定到 640×480 留出图生成目标。输出边缘 10 像素单独记录，避免外部反射填充和当前学生零填充造成边界误判。

### 阶段 B：固定图学生蒸馏

新增 `algo/train_art_styles_v21.py`，初始化 `runs/art_styles_c24_v19_expanded_skill/student.pt`，不修改 `tinystyle.py`。每个 batch 计算：

```text
L_student = L_gram + 0.18 L_content
          + 0.20 L1_masked(y_fp32, T_fns)
          + 0.10 L_grad(y_fp32, S_mix)
          + L_style_region
          + 0.18 L_temporal
          + 0.005 L_TV
```

`L_style_region` 使用现有 v19 的三个分支；只增加教师目标，不增加部署运算。前 30% 步数只用 `α=0.15`，中间升到 0.25，最后升到 0.35，避免学生丢失主体。

### 阶段 C：整数一致性 QAT

重新生成 v21 自身 qparams，再用已有硬件算术合同训练 QAT。QAT 的目标同时包含：

```text
L_qat = 5.0 L1(y_int8, y_fp32)
       + 1.0 L1(y_fp32, T_fns)
       + 0.35 L_gradient(y_int8, y_fp32)
       + 1.50 L_ukiyo_hard_flat
       + 0.50 L_ink_region_balance
```

所有候选都必须重新运行 24 图留出集、30 帧真实相机回放、图核对和整数 golden；不复用旧 qparams。

## 预期效果与筛选门槛

下表是实验目标区间，不是已实现结果；最终以同图盲评和实际测量为准。

| 指标 | v19 实测基线 | v21 目标 |
|---|---:|---:|
| 梵高 FP32/INT8 表面高频 | 0.033 / 0.049 | FP32 提升约 20–40%，INT8 不超过 FP32 的 1.25 倍 |
| 梵高 INT8 edge-F1 | 0.904 | ≥0.90 |
| 浮世绘 FP32 块内平坦 | 0.340 | ≥0.34 |
| 浮世绘 INT8 块内平坦 | 0.193 | ≥0.25，同时边界梯度不下降超过 10% |
| 水墨 FP32 纸白比例 | 0.753 | 0.72–0.82 |
| 水墨 INT8 纸白比例 | 0.873 | 0.75–0.85，主体暗度不超过 0.60 |
| INT8 对自身 FP32 SSIM | 0.846 / 0.849 / 0.856 | 各风格至少 0.88，目标 0.90 左右 |
| INT8 对艺术参考 SSIM | 0.894 / 0.894 / 0.898 | 不低于 v19，优先达到 0.90 |
| FPGA 图 | v6 一致 | 必须保持一致 |

如果教师蒸馏让风格变强但 INT8 自身 SSIM、边缘 F1 或水墨分区失败，该候选直接淘汰。PSNR/SSIM 只能在风格门槛通过后用于排序，不能用高保真掩盖风格变弱。

## 结论

可以借鉴外部项目的**训练逻辑、VGG/Gram 监督、InstanceNorm 经验和教师蒸馏思路**；不能借鉴其重型生成器作为当前 FPGA 部署网络。最合理的 v21 是“外部 FNS 教师 + v19 区域风格监督 + 固定 v6 学生 + 合同一致 QAT”，预期提高可见笔触/色块/墨层，同时把 v19 的 INT8 保真度和时序稳定性作为硬约束。
