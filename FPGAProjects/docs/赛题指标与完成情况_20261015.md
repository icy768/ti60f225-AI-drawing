## 2. 最新主链路实机证据：RISCV10

用户完成 RAM 下载后，COM19 / 115200 / 8N1 的采样覆盖运行时间 122000～162000ms，共 21 条状态、40 秒，布局为分屏；三次 UART 风格切换为 0→1→2→0。

| 指标 | 结果 | 能证明的范围 |
|---|---|---|
| 风格帧率 | 29.99～30.00fps | 当前 VGA 网络在该短时窗口内跟上约 30fps 输入 |
| 摄像头计数 | 约 29.9fps | SC431HAI 采集，不是网络处理分辨率 |
| 网络耗时 | 32.9～33.2ms，历史峰值字段 33.3ms | 包含板端实际等待；离线作业约 30.45ms 不能直接替代它 |
| 稳态跳帧 | 总 skip 保持 186，run_skip=0 | 观察窗口内无新增跳帧；启动期累计跳帧未被抹去 |
| 切换到 HDMI 换帧确认 | 48.536 / 48.675 / 52.534ms | 三次 UART 操作均 <100ms；不包含显示器发光延迟 |
| 采集、视频、HDMI、IRQ 错误及欠流 | 均为 0 | 该窗口未出现新增错误 |

证据入口：[RISCV10 发布说明与串口日志](https://github.com/icy768/ti60f225-AI-drawing/blob/codex/resource-throughput-20261013/FPGAProjects/烧录文件/20261015_RISCV10_LowLatency_Candidate/README.md)、[资源与 30fps 来源](https://github.com/icy768/ti60f225-AI-drawing/blob/codex/resource-throughput-20261013/FPGAProjects/docs/资源复核与30fps来源_20261015.md)。K0 布局功能另有用户上板确认，但不能将它等同于 RISCV10 所有布局、按键组合的完整长时验收。

## 3. 分辨率与性能的统一表述

- 摄像头输入为 SC431HAI **1920×1080 RAW10、约 30fps**。
- 经 BGGR 去马赛克、颜色处理、中心裁剪及 2×2 平均后，神经网络实际输入输出为 **640×480**。
- RISCV10 实机短时风格处理为 **29.99～30fps**；当前性能介绍应使用这一版本的证据。
- HDMI 为 **1920×1080@60Hz 显示扫描**，包含放大与重复扫描，不是 1080p 神经网络推理。
- 手机预览候选为 **96×54 RGB565**，尚无实际无线帧率记录；浏览器轮询次数不代表新增图像帧数。
- **真实 1280×720@30fps 推理尚未完成**；当前内部换帧确认时间不等于摄像头到屏幕的完整时延。

| 1280×720@30fps 或更高实际推理 | 未完成 | 不能用 HDMI 输出时序替代 |
| 参数 <500KB | 已完成规模目标 | 11,028 参数，blob 48,616 B；整机资源另列 |
