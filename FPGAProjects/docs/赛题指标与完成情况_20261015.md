## 画质指标与已有结果

### 怎么量化

| 指标 | 回答的问题 | 使用方式 |
|---|---|---|
| 真实处理分辨率 | 网络到底处理多少细节 | 目前 640×480，单列 HDMI 扫描分辨率 |
| PSNR（dB） | 与同尺寸、对齐参考图的像素误差多大 | 相同参考下越高越接近；必须说明是 FP32 教师、量化前模型还是原照片 |
| SSIM | 结构、亮度和对比关系与参考是否相似 | 同一评估协议下越接近 1 越相似；不是识别准确率 |
| 主体结构 / 边缘 F1 | 风格增强后人脸、轮廓是否保留 | 配合逐图查看和风格强度评估，不能单独当艺术分数 |
| 风格特征 | 梵高笔触、浮世绘色块、水墨留白和浓淡是否明显 | 现有项目含纹理、平坦区域、轮廓梯度、纸白/浓墨等内部指标；无官方统一阈值 |
| 视频稳定性 | 运动时是否闪烁、纹理跳动、亮度呼吸 | 静态场景统计 + 运动对齐后的帧间误差；需 SC431HAI 实板视频复验 |
| 原图质量 | 曝光、偏色、细节、噪声和边缘伪色 | 固定灯光/曝光的场景对照；当前有手动 RGB 增益，未实现完整自动曝光/自动白平衡 |

PSNR/SSIM 评的是与所选参考的接近程度。风格迁移会主动改变颜色和纹理，因此不能一味提高“风格画对原照片”的 PSNR 来选择模型；应同时检查内容结构和艺术风格。指标可参考 [scikit-image 官方说明](https://scikit-image.org/docs/stable/api/skimage.metrics.html) 及 [SSIM 作者说明](https://ece.uwaterloo.ca/~z70wang/research/ssim/)。

### 当前模型已有的离线评估

协议：24 张留出 RGB 图，640×480，uint8 RGB，逐图计算后取均值。参考为 `v21b_ukiyoe_color_block` FP32 艺术教师；不是原始照片，不是 SC431HAI/HDMI 的画质实测，也不是标准 CycleGAN 对照。旧 JSON 中 `*_vs_v10` 是历史字段名，实际教师身份以路径与 SHA256 为准。

| 风格 | INT8 对艺术教师 PSNR | SSIM | 边缘 F1 | INT8 对自身 QAT 浮点输出 PSNR / SSIM |
|---|---:|---:|---:|---:|
| 梵高 | 25.14 dB | 0.8851 | 0.9043 | 22.12 dB / 0.8435 |
| 浮世绘 | 27.20 dB | 0.8867 | 0.9168 | 24.46 dB / 0.8445 |
| 水墨 | 26.29 dB | 0.8901 | 0.8604 | 22.97 dB / 0.8518 |

数据源：`../StyleCam/audits/v21b_ukiyoe_qat900_soft15_paired24/summary.json`。两种参考对象不可混用。现有数据表明量化保持程度仍有改善空间，不能宣称艺术质量达到某个官方分数。

另有 30 帧 PC USB 相机回放，整数 golden 运动对齐帧间 MAE（255 制）为梵高 14.37、浮世绘 7.36、水墨 7.01；来源为 `../StyleCam/audits/v21b_ukiyoe_camera30_integer/summary.json`。这组数据用于同场景同风格跨版本比较，不是板端 FPS，也没有官方及格门槛。

RTL 与整数参考的像素一致性回归已经通过，它证明实现算术一致；动态 IN 的实际历史状态和摄像头输入仍会影响最终画面，不能直接把离线分数等同于屏幕观感。

## 最新编译资源与建议顺序

Resource2 完整布局：56,287 / 60,800 XLR，235 / 256 RAM10，121 / 160 DSP；剩余 4,513 XLR、21 RAM10、39 DSP。模型和精度未缩减。此数据归属于发布包，当前板上位流具体哈希仍未独立确认。

结合用户允许不强推 30 FPS 的方向，后续优先：

1. 保持 VGA 稳定超过 15 FPS，补齐三风格长时间运行、切换帧序列和端到端时延记录。
2. 用固定场景改善原图曝光/白平衡、风格强度和视频闪烁，优先尝试不增加部署图的训练/量化改进。
3. 补完整标准网络对比和网络结构图，将已有工程证据转为提交材料。
4. 选择一项创意交互增强演示；手势、语音、手机推流不必全部堆入 FPGA。720p30 作为单独的高阶目标核算。
