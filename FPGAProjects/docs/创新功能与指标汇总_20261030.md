## 1. 系统概况

| 项目 | 当前正式版（[20261031_RISCV11_Creative_Release](../烧录文件/20261031_RISCV11_Creative_Release/README.md)） |
|---|---|
| 器件 / 摄像头 | 易灵思 Ti60F225；SC431HAI，1920×1080 RAW10，MIPI CSI-2 |
| 预处理 / Resize | BGGR 5×5 MHC 去马赛克、Gamma、RGB 增益、自动曝光；中心裁剪 1280×960 + 2×2 平均 → **640×480** |
| 网络 | 自设计 V21b 13 层 INT8 CNN（3×3 / 1×1 / 深度卷积、残差、PixelShuffle），板内定点 IN |
| 风格 | 梵高、浮世绘、水墨三种，以及任意两种之间 9 档混合；共享卷积权重，各风格独立 IN 参数 |
| 输出 | HDMI 1080p60：原画 / 风格画对比、风格全屏、原画全屏、Resize 原图 1x / 1.5x / 2x；OSD 显示 FPS / 风格 / 混合比例 |
| 控制 | Sapphire RISC-V：摄像头 I²C、Flash 模型加载与 CRC、加速器调度、UI |
| 交互 | 板载按键；ESP32-S3 热点网关 + VC-02 语音；手机中文控制页（最多 4 台同看） |
| 资源 | XLR 57256 / 60800（94%），RAM10 **255 / 256**，DSP 145 / 160；setup +0.302 ns，hold +0.026 ns |
| 固化 | 配置 Flash 写入并整片独立回读一致；RESET_N 自主启动通过 |

**资源约束**：RAM10 只剩 1 块，RISC-V 固件内存只剩 **16 B**（16368 / 16384 B，含 2 KB 栈），XLR 约 3500 空余。新功能优先放在 **ESP32 / 手机 / 电脑** 侧，FPGA 只做"复用现有结构"的改动；再加固件功能需先删减。

## 5. 硬件与连线（高清录制，可选）

**采集卡选购**：HDMI 输入必须支持 **1920×1080@60Hz**；USB 免驱（UVC）；录制至少 1080p30；最好带 **HDMI 环出**。
- 入门：MS2109 芯片 USB2.0 采集卡，约 30～60 元，录 1080p30，一般没有环出，需加 HDMI 一分二分配器（约 30 元，要支持 1080p60，注意给它供电）。
- 进阶：USB3.0、带环出、能录 1080p60（常见 MS2130 芯片），约 150～300 元。

**连线**
```
带环出：FPGA HDMI → 采集卡 IN；采集卡 OUT → 显示屏；采集卡 USB → 电脑
不带环出：FPGA HDMI → 分配器 IN；OUT1 → 显示屏；OUT2 → 采集卡 IN；采集卡 USB → 电脑
```
电脑共 3 根 USB：采集卡（直插，USB3 卡插蓝色口）、FPGA JTAG / 日志、ESP32（COM 口，用于接收录制命令）。

**OBS 设置**：视频采集设备 1920×1080；只录风格画时裁剪（对比布局：左 960、上 180、下 180；风格全屏：左右各 320、上下各 60）；录像格式用 mkv 再重新封装为 mp4；开启 WebSocket 服务器供桥接脚本控制。

**素材保存位置**：电脑录制存在 OBS 指定的文件夹（例如 `D:\StyleCam素材\`）；手机拍照、录像存在手机"下载"目录（苹果在"文件"App 的"下载"里）。App 内置浏览器可能拦截下载，请用 Chrome 或 Safari。
