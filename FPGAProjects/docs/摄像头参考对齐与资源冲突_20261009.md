## 已确认的冲突与接口适配

1. **CSI FIFO 4096 无法装入当前 Ti60。** 实际综合与布局检查需要 271 个 RAM 块，器件容量 256，Efinity 报 `Not enough physical locations for MEMORY blocks : capacity=256 usage=271`。经用户选择保留 1024；失败报告保存在 `validation/camera_original_align/fifo4096_conflict`。不能把历史“共节省 42 RAM”的记录当成本次 FIFO 单项开销；本次以实际报告为准。
2. **原 VIO 接口与现有 CPU 控制接口不同。** 保留 APB/UART，使 RISC-V 和串口功能继续工作；数值宽度、默认值、零值规则及运算与参考对齐。调节在传感器新帧起点原子生效，避免一帧内三个通道混用新旧值。
3. **原 RAW DDR／显示端插值与网络 RGB 输入架构不同。** 集成工程保留 CSI 端插值、RGB DDR 与网络输入路径，否则须重写网络前端及显示缓冲。已对齐像素运算，但没有声称原 RTL 模块或内部延迟完全相同。2×2 RGB 平均属于保留画面尺寸所需的缩小步骤。
