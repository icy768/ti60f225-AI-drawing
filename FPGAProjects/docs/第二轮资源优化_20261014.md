# 第二轮资源优化

基线为 `20261014_RISCV09_K0_Layout_Candidate`：XLR 57,105、RAM10 239、DSP 121。K0 切布局、KEY3 操作、底部精简 OSD、PE6 网络均继承本基线。交付仍由用户手动下载。

## 实现

1. **ALU 指令直连**：sc_in_math 在 ALU 接受命令的时钟边沿直接提供输入，不再另存两份 160 位命令操作数。各阶段仍保留所需输入快照。
2. **复用 gamma/gain 存储**：原 gamma 只在求增益之前使用，同一 112 位寄存器在除法完成后保存增益。
3. **消除宽偏置中间快照**：原始 beta 只保存 56 位；宽偏置结果直接衔接取绝对值和舍入操作，只另存符号位。s2 原始统计量保持 60 位，乘 n 后直接进入差值运算。
4. **归一化常量串行 ROM**：10 个参数银行和 3 个 epsilon 银行，每个为 512×20。每通道依次读取六个参数字、五个 epsilon 字。去掉每层补齐到 24 通道的无效条目，三风格各保存 272 个有效通道。
5. **固定对齐的无损编码**：gamma 原来的 40 个零低位之外再去掉 4 个零位，保留有符号 61 位；beta 保留原 56 位；epsilon 去掉 40 个零低位，保留 88 位。生成器对整除、符号宽度和逐字还原作断言，无法表示的新常量会报错，不能静默截断。该布局已验证覆盖当前 VGA 模型及 32×24 验证模型，不保证任意重新训练模型都能直接套用。

最初的可变指数解码虽然释放五块 RAM，但布局逻辑增加 92 XLR，因此未交付。最终采用固定对齐形式，减少解码器的移位与寄存器成本。最终资源与时序以交付包报告为准。

## 验证

- 3,273 个 IN 算术向量与官方黄金结果一致，包含真实 VGA 统计、随机/全黑/全白图及正负数边界、零样本和复位。
- 最长算术周期由基线 3,318 变为 3,304。串行常量读取另外增加少量控制周期，不能仅用算术周期换算板上帧率。
- 从实际 13 个 ROM 文件解码，816 个有效 304 位常量字精确等于原文件，包括 272 个跨风格共享 epsilon。没有改动模型权重、量化精度、图像尺寸或画面公式。
- ALU 1,260 个向量和异步上传 1,536 像素测试通过；上传模块本轮未变。
- 最终三风格动态归一化网络回归与完整布局布线检查完成后记录到发布包 manifest。打包检查拒绝早于修改时间的仿真可执行文件和旧测试结果。
- 完整三风格回归最终通过：6,912 像素、936 系数一致，包含初次校准、动态刷新、背压和复位；额外的实板 VGA ROM 读取 RTL 测试也逐一验证 816 个原始字和系数。

## 复现

先运行 `compact_in_constants.py`、`check_serial_in_constants.py` 生成并检查常量银行，再执行 `sim_in_math.py`、`sim_serial_constants.py`、`sim_video_engine.py`、`sim_optimization.py`。完整 VGA 静态网络证据与相关 RTL、权重保持一致，本轮无需重复未变的卷积网络性能比较。

构建目录为 `%TEMP%/stylecam_resource2_20261014`，依次执行 `build.py interface`、`build.py map`、`build.py pnr`、`fw_update.py <build_dir>`，最后：

```text
package_optimization.py <build_dir> --profile resource-key1 --key3-tap-hold --clean-osd --k0-layout --resource2
```

Python 使用 UTF-8；算术及网络参考使用现有 PyTorch 环境，综合使用 Efinity 2026.1。

## 最终布局结果

| 资源 | K0 基线 | 本轮布局 | 节省 | 剩余 |
|---|---:|---:|---:|---:|
| XLR / 60,800 | 57,105 | 56,287 | 818 | 4,513 |
| RAM10 / 256 | 239 | 235 | 4 | 21 |
| DSP / 160 | 121 | 121 | 0 | 39 |

相对最初 RISC-V 08 的 60,399 XLR / 246 RAM10 / 121 DSP，累计节省 4,112 XLR、11 RAM10，DSP相同。不能将累计差额全部归因于本轮。

归一化更新层级归属估算为 5,929.5 XLR、13 RAM10，基线为 6,642.5 XLR、17 RAM10。其中 math 子模块从 6,493.5 XLR / 1 RAM10 变为 5,090 XLR / 0 RAM10；串行读表增加了控制逻辑，所以整个模块的净逻辑节省小于 math 子模块的差值。层级估算与整体布局差值也会受到打包和跨模块重映射影响。

最终布线 PASS。setup 最小 +0.233 ns、hold 最小 +0.026 ns、100 MHz 核心 setup +1.447 ns。与基线 +0.276 / +0.026 / +1.942 ns 比较，本轮时序余量降低，仍满足原约束；不宣称提高 Fmax。

交付包目录为 `../烧录文件/20261015_RISCV09_Resource2_Candidate`，测试与源文件哈希以随包 manifest 为准。2026-10-15 用户已确认 K0 布局切换正常；COM19 查询读到 k0=6、输出 16.49–16.50 FPS、摄像头约 30 FPS、错误/欠流计数为 0。串口未识别当前板上位流 SHA256，因此不将 Resource2 发布包整体改为已上板验收；上电初始化、三风格长时间稳定性及具体位流身份仍需补齐。未自动下载或写 Flash。详细赛题核对及原始证据见 [赛题指标与完成情况](赛题指标与完成情况_20261015.md)。
