# 第四轮动态 IN 等价优化（2026-10-17）

> 2026-10-18 更新：同一 BIT 已通过用户画面确认、三风格短时采样、Flash 独立回读和 RESET_N 自主启动，已提升为[正式版](../烧录文件/20261018_RISCV11_Main_AE_IN4_Release/README.md)。以下保留 10 月 17 日离线构建时状态。

本轮按授权修改推理引擎内部的动态 IN 硬件，以第三轮候选为基线。13 层卷积结构、PE12、INT8 精度、训练权重、动态 IN 数值规则、摄像头像素处理、RISC-V 固件及所有时钟约束保持不变。自动曝光保留，自动白平衡与手机预览默认关闭。

## 实际修改

1. `rtl/sc_in_alu.v`：除法和开方采用非恢复余数形式，余数与结果复用按字写入的工作寄存器；除法用消耗后的被除数寄存器保存商，开方用另一操作数寄存器保存根。去掉独立的大位宽余数、部分结果和商寄存器，字内移位携带边界位。保留乘法模 2^160、整数开方、加减借位、除零、复位和 nearest/ties-to-even 舍入。`result` 在 `done` 时有效，运算期间用作工作存储。
2. `rtl/sc_in_refresh.v`：epsilon 常量以最多 53 位有效整数及 7 位移位数无损存储，每通道从 5 个二十位字减少到 3 个。读入后逐拍左移，完整恢复原 136 位 epsilon；不改变计算精度。常量 ROM 从 10 个参数银行加 3 个 epsilon 银行，变为 10+2。
3. `compact_in_constants.py`：增加 `.ec0/.ec1` 生成及逐项重建断言。所有原始模型、权重和旧常量文件保持原字节内容；新增文件仅为等价存储布局。

`sc_in_math.v` 的控制器无需改动，继续按 `done` 采样。当前实现没有引入 Flash 预取、APB 新寄存器或固件扩展；常量仍在 FPGA 内，运行期 Flash 访问方式不变。

## 测量与验证

独立 ALU 综合使用相同选项：LUT 从 3624 减至 1889，FF 从 989 减至 528，加法单元均为 18，不使用 DSP 或 RAM。完整 IN 更新器独立综合从 4630 LUT / 2088 FF / 13 RAM 变为 3762 LUT / 1630 FF / 12 RAM。分模块结果用于筛选，整机净收益以最终布局报告为准。

整机 Efinity 2026.1 构建已完成，保持原约束、TIMING_3 / seed 0，布线器最多 120 轮；未调整时钟。最终报告如下：

| 项目 | 第三轮基线 | 第四轮 IN 候选 | 本轮变化 |
|---|---:|---:|---:|
| XLR / 60800 | 57115 | 55615（91.47%） | −1500 |
| RAM10 / 256 | 244 | 243（94.92%） | −1 |
| DSP / 160 | 145 | 145（90.63%） | 0 |
| 最小 setup slack | +0.327ns | +0.253ns | −0.074ns |
| 最小 hold slack | +0.013ns | +0.026ns | +0.013ns |

剩余 **5185 XLR、13 RAM10、15 DSP**。最终 17 项 setup 和 17 项 hold 关系均为正；推理域保持 150MHz，其 setup 余量 +0.648ns。固件仍使用 16080/16384 B（含 2048 B 栈），链接空间余量 304 B；本轮不消耗额外固件空间。

- 算术回归：8 位穷举乘除/加减、16 位穷举开方、160 位随机与边界，合计 337520 组，同时与 Python 任意精度整数和冻结第三轮 RTL 比对；覆盖 ties-to-even、除零、非法操作及复位。
- 真实 IN：复用独立 golden 生成的 3273 组统计量，含完整 VGA、三种风格、黑白图和边界；接受参考向量前校验模型文件一致。
- ROM：逐项检查三种风格全部 816 个原始 304 位字及对应系数，包含银行跨界。
- 实际网络：当前 PE12 的 13 层卷积，三种风格全部层的初始标定及前两层轮转更新，检查 6912 个像素和 936 个系数；覆盖风格无复位切换、输入/输出反压与复位。
- 完整 VGA：使用当前 100/150MHz 跨域引擎及周期性流停顿，检查 307200 个输出像素，包含该帧 layer 0 的 16 通道真实 IN 更新，单次仿真计算预算需小于 33.333ms。此项不包含真实 DDR/HDMI，也不能代替板上帧率。

### 可复核证据

`StyleCam_camera/validation/in_resource_20261017/baseline_sha256.json` 冻结修改前 150 个源文件；除两份 IN RTL 外，另外 148 个文件保持哈希一致，包含卷积、模型、固件、摄像头和工程约束。`baseline/` 保留第三轮源码，`candidate_a/` 保留本轮独立构建镜像。每项回归记录实际参与编译的源码、测试台和 golden 向量哈希；常量回归还检查原始 304 位字的完整重建。
