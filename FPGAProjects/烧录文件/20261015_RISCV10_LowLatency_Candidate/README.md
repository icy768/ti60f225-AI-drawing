## 手动验收

下载 BIT 后等待三风格启动校准结束。连续观察至少 30 秒并切换三种风格：目标是处理约 30fps、`run_skip` 不继续增长、错误计数不增加、`uf=0`、`scan_sw_us < 100000`。启动校准期累计 `skip` 非零不等于稳态持续跳帧。`NN` 为单帧任务耗时，`scan_sw_us` 为切换请求到 HDMI 换帧确认，不含显示器自身延迟。

可将含版本 ID 的完整串口日志交给 `StyleCam_camera/audit_latency_log.py` 检查；工具只读取日志。详细说明见 [优化记录](../../docs/低延迟与帧调度优化_20261015.md)，全部证据及哈希见 [manifest.json](manifest.json)。
