## 1. 单独接语音板

1. 语音板暂不接ESP32、FPGA的杜邦线，接好原配麦克风和喇叭。
2. 用**能传数据的USB线**把语音板接电脑。
3. `Win+X` → 设备管理器 → 端口(COM和LPT)，插拔对照，记下语音板的COM号，常见名称USB-SERIAL CH340。
4. 关闭占用该COM的串口监视器。已有正常COM就可继续；缺驱动时再安装本机已备份的 `CH341SER.EXE`，路径见完整教程第三节。

## 3. 下载到语音板

1. 工具中核对目标COM就是刚才识别的语音板。其他串口设备暂时断开，避免选错。
2. 当前用户实物复位键标为 **RESET**：USB保持连接，**按住RESET**。
3. 点击工具的 **“烧录”**；出现等待设备提示后，**松开RESET**。
4. 等进度到完成、该行变绿并显示“下载完成”，点击“停止”，关闭更新工具。
5. 重新上电，说 **“小安小安”**，等约1秒后直接说表中的命令。每条前重新说唤醒词。串口验收不以听到声音或指示灯亮为前提；有声音时再另行验收“一、二、三、四”播报。

此前KEY1/KEY2来自B207参考板图纸；当前实物用户报告为RESET、IOA20唤醒两个按键，实际已用RESET完成下载。本定制固件未配置出厂台灯控制、按键唤醒和指示灯逻辑，以说话后的串口数据判定识别结果。
一直等待时，先核对COM、数据线、端口占用以及模块是否实际复位；进一步处理见 [完整教程第三节](操作教程.md#三你做给-vc-02-更新语音词条)。

## 4. 验收语音板到ESP32

断电后用两根杜邦线连接：**VC-02 TX1 → ESP32 GPIO16，VC-02 GND → ESP32 GND**。两板各自USB供电。

1. 手机连 **StyleCam**，密码 **stylecam1234**，保持连接，打开 `http://192.168.4.1/`。
2. 打开语音面板并启用抓字节；`http://192.168.4.1/voice` 用于查看抓取数据。
3. 每次说“小安小安”，约1秒后直接说一条命令，逐条核对原始HEX是否与上表一致；不用等待回音或灯亮。
4. 四条全部对上后，语音板到ESP32这一段才验收完成。
