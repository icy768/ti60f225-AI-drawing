## 摄像头与自动曝光实现

- SC431HAI RAW10 → BGGR 5×5 MHC → 原 Gamma → 中心裁剪、2×2 RGB 平均 → VGA 镜像写入 DDR。Gamma 曲线文件不变。
- Gamma 采用每四个线性输入的基值加差值，降低组合查表成本；仍保持全部 256 种输入的精确输出，不增加图像 RAM。
- MHC 共享远邻和及绿色采样点的公共表达式。四种插值分子的范围均落在 -3060…7140，使用 14 位有符号运算，保持裁剪、流水延迟和输出像素一致。
- AE 在 Gamma 前的线性 RGB 上稀疏测光，中央 ROI 每帧 5400 点；亮度和按最大值收敛位宽，过曝计数只需饱和至判断阈值加一（169）。完整 RAW 帧结束后通过请求/ACK 发布快照。
- RISC-V 每 200ms 读取统计。亮度目标 64，死区 56～72；通过原 APB I²C 引擎，在 `3812` 分组中更新曝光和模拟增益，保持 VTS 与摄像头帧周期。曝光范围为 4…`2*VTS-12`。
- I²C 写失败重试三次；中途失败尝试释放分组，保留待重写状态。串口输出 AE 亮度、曝光、增益及错误计数，AWB 保持 OFF。
- 固件重新编译为 13746 字节，链接 RAM 16080/16384 字节，包含预留的 2048 字节栈。可选语音关键词模式关闭。

神经网络 RTL、13 层结构、权重、INT8 精度、动态 IN、PE12 与原有推理调度未修改。与开始任务时的源码快照核对，235 个受保护 RTL/模型/IP/固件文件逐字节一致；原 SDC 也一致。

## 验证范围

| 验证 | 结果 |
|---|---|
| 原曲线与优化 Gamma | 256 种输入 × 12 个通道路径全部相同 |
| 小尺寸完整 MHC | 384 个 RGB 像素与独立整数卷积参考一致，含增益、裁剪、间歇输入及复位 |
| 完整尺寸 RGB 与镜像 DDR | 921600 个输出像素一致，行地址倒序、像素通道及帧标志正确 |
| AE 测光 | 小图及 1920×1080 的 ROI、5400 点、线性亮度、过曝饱和、间歇输入、快照保持/ACK/复位通过 |
| APB/I²C | 新统计寄存器、RGB 提交、既有事件和 I²C 事务通过 |
| 实际 AE 固件函数 | 增益表、初始化、死区、上下限、200ms 节流、快照去重、分组寄存器、重试/释放/恢复、定时器回绕通过 |
| 可选预览 RTL | RGB565/RGB332，小图、真实 1080p60、快 1% 光栅及强制溢出恢复共 7 项通过 |
| ESP32 主机回归 | 6/6，通过全部 256 种 RGB332 颜色及格式交替、CRC、非法帧头和快照检查 |

镜像测试原本不消费 READY 帧，与当前“替换未消费帧计为 skip”的调度规则不符。本轮将测试接收端改为及时领取/释放完整帧，仍要求像素逐点一致且 skip/overflow/error 为零；没有修改采集调度器来规避此检查。

可选预览 FIFO 从 16×4096 缩至 8×1024，综合确认从 8 块降为 1 块 RAM10。96×54 RGB332 仅降低手机预览颜色精度，ESP32 发布接口仍使用 RGB565。1080p60 正常缓存峰值 442，快 1% 光栅为 490，均低于 1024。当前 AE 包关闭该功能，预览结果不能替代 ESP32 原生编译和实际手机联调。
