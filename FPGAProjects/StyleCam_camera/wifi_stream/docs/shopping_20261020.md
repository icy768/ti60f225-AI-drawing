## 实际使用的 5 根杜邦线

| 连线 | 作用 |
|---|---|
| VC-02 TX1 → ESP32 GPIO16 | 语音数据 |
| ESP32 GPIO17 → 子卡 J28-37 | FPGA 控制命令 |
| 子卡 J28-39 → ESP32 GPIO18 | FPGA 预览数据 |
| 子卡 J28-35 或 J28-36 → ESP32 GND | FPGA 共地 |
| VC-02 GND → ESP32 另一处 GND | 语音板共地 |

按丝印找 GPIO 和信号名称，不按排针的视觉位置猜。语音板资料中的引脚图是底视图。
3Mbaud 预览使用短线，地线靠近信号线，实际稳定性仍需板测。

ESP32 和 VC-02 若未焊公排针，需要先焊好；可让卖家或维修店焊接，不必为本次接线专门购买整套焊台。
如果 ESP32 只有一个方便使用的 GND，才需要额外准备一只绝缘的地线分线端子；通常有多个 GND 可直接分别连接。

## 按需用品

- 没有万用表：建议备 1 只可测直流电压、通断的数字万用表，用于上电前核对地线及电压。
- 需要长期摆放：备绝缘垫、尼龙支柱或合适的绝缘固定材料，避免裸板背面接触金属。
- 不必为这套方案购买面包板、1.8V↔3.3V 电平转换器、USB 转 TTL 小板、独立 JTAG 下载器或额外稳压模块。

## 供电与软件状态

FPGA 用原配电源；ESP32 与 VC-02 分别从自己的 USB 接口取 5V。可以用两根 USB 线分别接电脑供电足够的 USB 口，不必另买充电头或电源模块；语音板一路需满足其 >500mA 供电要求，优先使用电脑 USB 3.x 口。三板共地，各板的 VCC / 5V / 3V3 不用杜邦线互接，子卡电源针脚留空。
烧录时电脑 USB 替换该板的充电头 USB，不再并接另一组电源。

ESP32 两种 USB 配置的固件已编译，Arduino 工具链、VC-02 更新工具与驱动包已下载；未安装系统驱动，也未烧板。
尚需生成项目语音词条固件，以及完成新引脚映射的 FPGA 完整构建与时序检查，随后才能做实物联调。
