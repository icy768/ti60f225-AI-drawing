## 1. 准备 FPGA 候选

以项目稳定整机为基线，在隔离候选中完成：

1. uart_rx 改到 GPIOL_04 / B3，即配套子卡 J28-37。
2. stream_tx 改到 GPIOL_06 / C3，即 J28-39，并释放旧的 GPIOL_01 网口复位脚。
3. 保留板载串口日志 uart_tx 与 JTAG。
4. 若需要手机画面，启用 PHONE_PREVIEW=1；当前保留的预览为 96×54 RGB332，UART 3030303、8N1。
5. 完成综合、布局布线及其余完整构建流程，审查时序和引脚报告，导出候选 .bit/.hex 与回退说明。

控制 UART 仍为 115200、8N1。现有 RISC-V 控制台已经实现 0/1/2/v/s，无需为了这些语音命令重写控制协议。
上述电脑端候选准备现已完成。当前正式 Flash 位流没有使用新映射，需按新包教程下载候选到 RAM 才能使用 J28-37/39。

## 2. 生成 VC-02 项目词条固件

在 [安信可离线语音平台](https://voice.ai-thinker.com/) 登录，选择 VC-02，配置唤醒词“小安小安”、UART1 115200、8N1。
Kit 的识别数据从 TX1 输出，平台引脚设置按 [VC-02 接入说明](voice_vc02.md) 核对。

| 命令词 | 原始 HEX 字节 | ESP32 转给 FPGA |
|---|---|---|
| 切换梵高 | A1 00 01 01 FF | 0 |
| 切换浮世绘 | A1 00 02 01 FF | 1 |
| 切换水墨 | A1 00 03 01 FF | 2 |
| 切换画面 | A1 00 04 01 FF | v |

2026-10-22 用户确定只用上表四条，回复语依次为“一、二、三、四”，不添加“当前状态”；现有ESP32固件已支持这四组数据，无需因此重编译。
填写清单为 [voice_commands.csv](../../../烧录文件/20261021_ESP32_VC02_J7_Integration/voice/voice_commands.csv)，不是平台导入文件，也不是固件。
取得对应的串口更新文件 uni_app_release_update.bin 后，使用本机 UniOneUpdateTool 更新。
工具包自带的默认 bin 不包含本项目词条；JTAG 完整镜像 uni_app_release.bin 也不能改名替代串口更新文件。
2026-10-23已取得纯离线VC-02版本20261023001。唤醒词“小安小安”、四条用户命令及回复、UART1 115200/8N1、A28低、原始字节发送核对通过，见 [下载产物记录](../../../烧录文件/20261021_ESP32_VC02_J7_Integration/voice/generated_sdk_verification_20261023.json)。下一步按 [语音板烧录教程](../../../烧录文件/20261021_ESP32_VC02_J7_Integration/下一步_语音板烧录.md) 更新模块。

官方 [VC 资料页](https://docs.ai-thinker.com/vc/) 当前提供语音平台、串口更新工具、驱动及烧录指南入口。

## 3. 联调所需电脑准备

- 确认 ESP32、VC-02、FPGA 各自的串口号；之前 ESP32 是 COM28，重新插拔后不能保证仍是这个号。
- 已能识别的设备不用重装驱动；只有设备管理器缺驱动时，再安装对应驱动。不要把 ESP32 的 COM 口选为 VC-02 更新目标。
- 串口日志用 115200、8N1；烧录器与串口监视器不要同时占用同一端口。
- ESP32 电脑线接板上标 COM 的 USB 转串口口，当前使用 usb_uart 应用；native_usb 尚未实物验证。
