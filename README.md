# Ti60F225 + IMX219 摄像头工程

本仓库保存 Ti60F225 开发板上的 IMX219 摄像头例程、独立彩条诊断版，以及当前调试记录。摄像头通过 J7 扩展子卡的 U1 接口连接；请勿仅凭排线针数或方向标记判断供电和信号兼容性，务必先核对硬件接线。

## 目录

| 路径 | 内容与状态 |
| --- | --- |
| `projects/vendor_example/` | 商家提供的 `Ti60f225_imx219hai2hdmi_v7` 原工程及原 bit；此前已在板上得到实时画面，但画面偏绿、偏暗。 |
| `projects/diagnostic_colorbars/` | 从商家工程复制的独立诊断版，使 IMX219 输出内置彩条；已用 Efinity 2026.1 生成 bit，**尚未上板验证**。详见该目录的 `诊断说明.md`。 |
| `experiments/imx219_safe_bringup/` | 摄像头安全启动 RTL 与测试台实验；不等同于已跑通的完整摄像头工程。 |
| `docs/` | 开发环境、官方例程及阶段性交接文档。`项目进度交接_20260928.md` 是历史快照，不代表当前摄像头进度。 |

## 使用与下一步

1. 在 Windows 上安装 Efinity 2026.1，分别打开两个工程目录中的 `ti60f225_oob.xml`。工程路径尽量使用不含中文和空格的短路径。
2. 先确认开发板、J7 扩展子卡、摄像头排线及显示设备的连接；**断电后**才插拔排线或子卡。
3. 可先用 `projects/vendor_example/outflow/ti60f225_oob.bit` 恢复实时画面基线，再按 `projects/diagnostic_colorbars/诊断说明.md` 测试彩条 bit，借此区分传感器曝光问题和图像处理链路问题。
4. 当前尚无彩条上板结果，也没有证明偏绿、偏暗的根因；不要将诊断版视为已修复的正式驱动。

`docs/官方例程跑通教程.md` 介绍基础操作流程。工程中含商家及芯片厂商提供的文件，原有权利归各自权利人；本仓库未对这些第三方内容声明新的开源许可。
