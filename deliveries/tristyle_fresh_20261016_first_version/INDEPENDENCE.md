# 独立设计与来源边界

创建时间：2026-10-16 22:19 Asia/Shanghai。交付截止：2026-10-17 10:00 Asia/Shanghai。

本目录是从零建立的独立项目。禁止导入、读取、复制本机旧网络的结构、权重、损失实现、训练方案与配置。允许复用 Python/CUDA 计算环境和明确获授权的原始图像。本项目没有读取本机任何旧网络文件；根目录名称仅用于选定新目录。所有新增代码在本目录编写，外部教师与数据单独记录 URL、许可状态、哈希与用途。

教师检索设为约 35 分钟的首轮时间盒。可用教师立即进入固定多场景实测；水墨教师不可用时采用可追溯艺术参考图与直接风格优化，不等待不明来源权重。教师权重不进入学生部署包。

500KB 按较严格的 500000 bytes 计算，包括全部共享层、全部三专家、偏置及量化元数据。硬件吞吐、存储与带宽在没有 RTL/板卡运行结果时只作为估算。训练 loss、参数规模与输出文件的存在均不代表艺术验收通过。
