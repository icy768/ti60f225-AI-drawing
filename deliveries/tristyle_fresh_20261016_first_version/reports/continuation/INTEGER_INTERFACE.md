# 全三风格整数包接口

当前软件已执行验证，尚未实现或验证FPGA描述符加载器、完整卷积引擎及整网RTL。后补的抽样MAC/Q31/add-cat/RNE算术单元RTL已由Icarus13执行，范围和实际记录见rtl_math/README.md；不能将其等同整网、DDR3、综合或上板通过。

`TRIV3` JSON格式包含24字节头、压缩图描述和INT8权重/INT32偏置/Q31乘数/INT8指数。帧处理需要的input/add/cat/output整数常量也随包保存；浮点scale仅供诊断，不进入整数帧算术。旧格式可在装载时离线编译这些常量。

`TRV3HW1`固定格式不含JSON、压缩流或浮点字段，全部小端：

|部分|格式|含义|
|---|---|---|
|头64B|`<8s14I`|magic、version、总字节、卷积数、节点数、共享节点数、3个专家节点数、卷积表偏移、节点表偏移、参数区偏移/长度、默认宽/高|
|卷积记录80B|`<20I`|Cin/Cout、KH/KW、strideH/W、padH/W、groups、ReLU标志、输入/输出零点、权重/偏置/乘数/指数的参数区相对偏移、保守累加上界、3个保留字|
|节点记录64B|`<16i`|opcode、两个源节点序号、卷积记录号、源0的M/E/Z、源1的M/E/Z、输出零点、guard bits、源个数、3个保留字|
|参数区|16B对齐数组|有符号INT8权重，INT32偏置，INT32 Q31乘数，INT8指数；实际对齐填充计入总字节|

opcode：0=input，1=conv，2=add，3=cat（通道轴），4=nearest2，5=output。先执行共享节点，再执行帧开始时锁存的那个专家节点区间；其他专家只占存储，不并行占计算硬件。卷积尺寸/分组直接读表，不依赖外部Python网络定义。

卷积契约：`A=sum((X-Zin)*W)+B`，INT32累加；`Y=sat_u8(RNE(A*M*2^(E-31))+Zout)`；ReLU时再约束`Y>=Zout`。参考软件以INT64执行并检查INT32范围。打包器逐输出通道计算 `abs(B)+max(Zin,255-Zin)*sum(abs(W))` 的保守上界；这属于算术范围证明，不是DSP时序验证。

add/cat对每个输入先以Q31重定标，保留16个guard bits，残差先加再一次RNE移位并饱和。nearest2只复制整数码。input把RGB888转换成量化码；output用预存M/E把量化码转回RGB888。负数右移按向下整除定义商，再处理最近偶数舍入，不能依赖HDL的默认截断行为。

整包常量常驻DDR3；可以只缓存当前64B操作及80B卷积描述符，或缓存完整表。完整基线描述符表占15,664字节，应在CNN缓存预算中显式计入，不能当作免费BRAM。启动时需要外部主机或尚待实现的启动FSM写入DDR3；没有假定免费RISC-V硬核。CRC/启动链路、AXI突发、仲裁及资源占用待RTL/板卡验证。

固定包与JSON包是替代格式。部署选择一个，包内已含三专家。`hwpack.py`写出精确分项、sha256和500000字节检查；`IntGraph`可直接仅凭固定包执行整数推理。主机TorchScript使用oneDNN，和规范Q31在舍入位置可能不同，应保留两个后端的实际差异及图片。
