# 用户给定硬件与部署约束

Efinix Titanium Ti60F225，用户最初指定 F225 Development Kit。62,016 LEs；160 DSP；256×10Kbit BRAM，共 2.621 Mbit / 320 KiB；4 PLL。

**用户更正并提供原理图核实信息：板上外存是 DDR3。** 此更正覆盖此前 HyperRAM 配置。板卡为 Ti60F225I3-V4 DEMO，原理图 Ti60F225A_V4_SCH.pdf，图纸日期 2026-03-06。U12：Micron MT41J128M16JT-125，2 Gbit / 256 MiB，x16。现有工程 DDR 时钟 400 MHz，数据速率 800 MT/s；AXI 时钟 100 MHz。此处仅记录用户提供的硬件事实，没有读取旧网络或旧训练工程。

物理理论峰值：800e6 transfers/s × 16/8 bytes = 1.6 GB/s（十进制）。AXI 数据位宽、控制器实测有效率、仲裁策略、CNN 剩余资源仍未知，不能据此宣称实际吞吐。早期 HyperRAM 分析已作废。

以上为用户提供的芯片总资源，未经独立文档/板卡实测核验。CNN 必须给采集、显示、DDR3 控制器、缓存和控制预留资源。DDR3 实际频率、效率和剩余 DSP/BRAM 未测，分析必须参数化。RISC-V 如使用则为软核，必须计算资源开销。三风格复用 INT8 引擎，全部部署权重与量化元数据不超过 500000 bytes。

输入 640×480@30fps，目标输出≥15fps。只有 Efinity 综合、时序收敛、控制器测量及上板后才能确认实际吞吐；首版参数化分析不得声称已经达到。采用有界双槽输入、最新帧覆盖待处理槽、帧边界风格锁存，避免无限积压。必要时明确 2:1 抽帧和输出帧重复策略。
