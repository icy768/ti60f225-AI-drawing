# StyleCam v15 与开源 Skill 同图复核及下一轮优化定制

日期：2026-10-05

## 结论先行

当前 v15 已达到“推理图不变、主体边缘基本保留、三种风格可区分、内部参考集 PSNR/SSIM 过线”的阶段，但没有达到发现文档要求的“表面接近重绘、风格特征持续突出、INT8 与 FP32 稳定一致”的最终目标。

## 人工复核补充

用户对同图结果的观察与数据基本一致：

1. 梵高和浮世绘的 Skill 结果色彩更鲜艳，色彩与明暗对比更明显；
2. 梵高和浮世绘的 Skill 结果整体亮度更高；
3. 三种 StyleCam 输出都存在一定表面模糊，INT8 的局部高频增加不能直接等同于真实清晰度提升；
4. 当前水墨容易被看成黑白化，缺少 Skill 中的纸面、湿墨、边缘消散和干笔空间组织；
5. 梵高 Skill 的短曲线、密集、多尺度、随形笔触明显多于当前网络。

这些观察不是单纯的主观偏好：城市街道同图中，梵高 Skill/StyleCam FP32 的色度、梯度和高频分别约为 66.8/51.6、28.5/17.9、63.3/41.1；浮世绘分别约为 63.0/29.3、28.8/13.4，亮度约为 125.1/80.6；水墨 Skill 的纸白比例约 39.7%，StyleCam FP32 约 32.0%，而高频约为 76.9/39.9。INT8 在梵高和浮世绘上提高了高频与色度，但同时出现过暗或局部过冲，说明量化放大不能替代训练出稳定的表面结构。

## 同图视觉差距

对比中的 Skill 结果按照之前保存的三个开源仓库规则生成；它们不是同一 FPGA 网络，也不是成对真值。因此下面的判断以结构、风格机制和相对趋势为主。

### 梵高

开源 Skill 的笔触短、密、连续，沿建筑、树冠和路面方向排列，蓝黄互补和局部明暗起伏明显。v15 FP32 保留了建筑、车辆和道路位置，边缘较干净，但笔触更像低频方向性纹理，表面较平，颜色和亮暗起伏都弱。

同图统计：Skill 的平均色度约 66.8、梯度约 28.5、高频拉普拉斯标准差约 63.3；v15 FP32 分别约 51.6、17.9、41.1。也就是说，FP32 主要缺少可见的中高频笔触和互补色强度。INT8 的色度约 70.8、梯度约 26.4、高频约 58.7，表面更接近 Skill，但这部分增强伴随量化对比度变化，不能直接视为学到了连续笔触。

200 张留出图的主体边缘 F1 从 v6 的 0.845 提升到 v15 的 0.927，说明主体轮廓保护有效；但当前指标只说明边缘位置，不说明笔触是否连续。因此梵高目前是“结构通过、表面笔触部分通过”。

### 浮世绘

Skill 输出的主要依据是有限主色、较亮的纸面、清晰的深色木刻轮廓和块间分界。v15 FP32 的大轮廓还在，但整幅偏暗、偏灰，边界有扩散，局部颜色版块和主版线不够突出；INT8 提高了边界梯度和色度，却出现整体偏黑、局部过硬的倾向。

同图统计：Skill 的平均亮度约 125.1、色度约 63.0、梯度约 28.8；v15 FP32 约 80.6、29.3、13.4；INT8 约 77.0、43.7、20.1。v15 FP32 的平坦比例约 0.367，说明有大块平滑区域，但这些区域没有同时形成足够清楚的边界；这与发现文档中“块内简化和块间清晰轮廓”两个条件不同。

200 张留出图的 edge-F1 为 0.931，平均块内平坦比例为 0.345，边界梯度为 0.102。边缘位置已改善，但块面色彩、纸面亮度和边界硬度没有达到 Skill 参考的视觉强度。因此浮世绘目前是“边缘通过、版块和调色失败”。

### 水墨

Skill 输出把真实建筑、树木和车辆组织成浓墨主体、淡墨背景和纸白外缘，干湿边缘及飞白纹理明显。v15 FP32 已经降低色彩并保留主体，但城市场景中纸白外围还不够连续，背景偏灰，干笔高频不足；INT8 的纸白和主体黑白对比更强，却出现大面积过黑，量化后空间墨密度分配发生偏移。

同图统计：Skill 的平均亮度约 168.3、色度约 6.4、纸白比例约 39.7%、高频拉普拉斯标准差约 76.9；v15 FP32 约 150.2、11.3、32.0%、39.9；INT8 约 142.7、11.0、37.6%、55.4%。因此 FP32 还不够亮、不够无色、高频不足；INT8 虽接近纸白面积，却暗部过重。

200 张留出图的背景纸白比例为 0.740、主体暗比例为 0.382、edge-F1 为 0.924，说明平均趋势已经接近目标；但单张城市街道和整数结果显示，空间分区仍不稳定。水墨目前是“平均统计接近、逐图和 INT8 分区未通过”。

## PSNR/SSIM 判定

当前 24 张整数评估相对既有 v10 艺术参考的均值为：

| 风格 | INT8 对 v10 FP32 PSNR | SSIM | 结论 |
|---|---:|---:|---|
| 梵高 | 25.17 dB | 0.876 | 达到当前内部筛选线 |
| 浮世绘 | 27.26 dB | 0.875 | 达到当前内部筛选线 |
| 水墨 | 25.63 dB | 0.873 | 达到当前内部筛选线 |

这三个数只能说明相对 v10 参考的保真度，不能证明达到官方或行业绝对标准。对部署更关键的 INT8 相对自身 FP32 均值为：梵高 21.42 dB / 0.818，浮世绘 24.08 dB / 0.817，水墨 21.43 dB / 0.812；三种风格的 SSIM 都低于内部建议的 0.85 一致性目标。城市街道单图对齐诊断更低，分别约为 20.10 / 0.780、21.76 / 0.768、18.94 / 0.736。

开源 Skill 与 StyleCam 的对齐 PSNR/SSIM 不能用作质量分数：Skill 图像编辑会改变画面重绘方式和边缘位置，像素不对齐是预期现象。它们只用于发现“纹理、色彩和明暗强弱”的差距。

## 定制优化措施

### 1. 梵高：只增加“可见连续笔触”，不统一提高饱和度

在训练监督中加入固定 Sobel/Scharr 方向场的局部一致性和多尺度带通能量损失：

- 以 5×5/9×9 窗口计算相邻笔触方向的 circular consistency；
- 只在中高梯度区域约束短划连续性，在平坦天空/墙面保留较低权重；
- 用 v10/筛选后的油画参考统计 band-pass 能量和 stroke-length 分布，目标是把 v15 FP32 的梯度和高频提高到参考的 80%–100%，不直接追求 INT8 的过冲值；
- 对主体边缘使用 signed-gradient 保留，防止纹理增强吞掉车、建筑和路灯轮廓；
- 保持当前颜色统计权重，新增的颜色项只做局部蓝黄互补，不做全图饱和度拉升。

### 2. 浮世绘：拆开“块内平坦”和“块间硬边界”

当前 `interior_variance` 已经压平局部变化，但没有保证硬边界和亮纸面同时存在。下一轮应：

- 将 8/12 色软调色板损失分成背景、主体和阴影三个区域，约束主色数量和色距；
- 在 boundary mask 上增加局部对比度和 signed RGB gradient，边界权重只作用于边缘带；
- 在 interior mask 上继续压低 5×5 局部方差，但对边界膨胀区禁用 flatness，避免轮廓被抹平；
- 增加亮度分位数目标，避免 v15 FP32 由大面积低亮输出造成“暗灰版画”；
- 训练后单独做 hard-flat QAT，限制 INT8 把块内细节重新打碎；
- 选择标准改为同时满足 flatness、boundary gradient、palette entropy 和 own-FP32 SSIM，不能只按 PSNR 选。

### 3. 水墨：改成主体/背景/边缘三分区墨密度监督

- 背景区域：约束纸白下限和低色度，目标是提高外缘连续纸白，而不是全图变白；
- 主体区域：约束暗部密度分位数和主体/背景对比，防止 INT8 把整个画面压黑；
- 边缘带：单独匹配干笔/飞白的带通能量和稀疏度，补足 FP32 的高频纹理；
- 取消只作用于主体的色度项，新增背景色度项并设置更低权重；
- 对亮部和纸面使用 tone-map/分位数损失，避免直接用全图均值把城市白墙误当成纸面。

### 4. 量化和时序作为共同约束

- 训练每 4 步执行一次 shift consistency 不够时，增加 1–2 像素平移、轻微曝光扰动和真实相机噪声的一致性；
- 对 temporal loss 同时比较低频亮度、边缘图和中频纹理，禁止纹理在相邻帧独立闪烁；
- 将最终筛选加入 own-FP32 INT8 gate：暂定每种风格 PSNR ≥24 dB、SSIM ≥0.85；这是工程内部门槛，不是官方标准；
- 每个候选都重新导出自身 qparams，做 24 图 FP32/INT8 对拍、30 帧相机回放，再决定是否进入 RTL；
- 水墨优先修正量化合同，因为当前 own-FP32 PSNR/SSIM 和城市单图差距最大。

### 5. 实验顺序

1. 固定 v6 图和当前数据，只改梵高局部方向/带通项，先做 8 图消融；
2. 从同一检查点只改浮世绘 palette+boundary 分解，比较块内平坦和边界梯度；
3. 只改水墨三分区墨密度和 dry-brush 项，检查纸白、主体暗部和 INT8 过黑问题；
4. 三个单因素候选分别重新 QAT，按风格门槛、own-FP32 SSIM、30 帧时序和盲评共同筛选；
5. 通过后再做 RTL 逐层对拍和 Ti60/SC431HAI 板端验证。

下一轮不应继续使用统一风格权重或单一 PSNR 作为选择标准；当前证据表明，问题已经从“有没有风格”转为“风格表面机制能否在 FP32、INT8 和视频时序中同时稳定存在”。
