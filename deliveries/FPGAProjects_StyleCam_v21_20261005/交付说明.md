# StyleCam v21b 交付说明

交付日期：2026-10-05。基线分支：`develop`。候选分支由本交付提交创建。

## 交付结论

本版选定 `art_styles_c24_v21b_ukiyoe_qat900_soft15` 作为可接入候选。v21 只改变训练监督和参数，推理图保持不变：C24/Fc16、4 个 `dw1` 残差块、13 层卷积、三风格条件 IN、640×480 输入输出、11,028 参数、339,148,800 个 VGA 卷积 MAC/帧。图核对记录为 `StyleCam/audits/v21b_ukiyoe_graph_vs_v6.json`，`graph_changed=false`，`quantization_validated=true`，`board_validated=false`。

## 实测验证

`StyleCam/audits/delivery_pc_v21_20261005/verification.json` 保存了交付副本的完整复验结果。同一 checkpoint、冻结 R/S 合同和 16 张 VGA 标定图用于导出；复验直接使用包内样本，不依赖完整数据集：

- blob 结构和 500 KB 检查通过；4,050 次 cfg 写入，48,616 字节。
- `rtl_style0`、`rtl_style1`、`rtl_style2` 均为 640×480，一帧/风格，13 层 mismatch=0，像素/统计量一致；使用同帧 IN 算术 oracle。
- `rtl_serialized_switch` 使用实际导出的初始 bank 和 cfg，48×32 三帧，不复位切换风格，通过逐层、像素和统计量检查。
- 三风格固件 IN 双 bank 刷新通过，M/B 最大误差 0，1,072 次写入。
- 生成的 RTL/mem/cfg 与交付文件逐字节一致；GCC 主机固件检查、SC431HAI/IMX219 两条分支语法和 blob/DDR 防错检查通过。
- 本版 SC431HAI `vision_top` 的 Efinity map 退出码 0；173 RAM10、125 DSP48、20,629 LUT4、14,388 FF。只覆盖视觉子系统，不证明整机资源、时序或板端帧率。
- 24 图风格/量化指标在 `StyleCam/audits/v21b_ukiyoe_qat900_soft15_paired24/summary.json`；同图 Skill/网络比较图在 `StyleCam/audits/v21_selected_city_comparison/`；30 帧 PC USB 相机代理结果在 `StyleCam/audits/v21b_ukiyoe_camera30_fp32/` 和 `..._integer/`。

关键 24 图 INT8 对 `v21b_ukiyoe_color_block` FP32 教师结果：Van Gogh 25.14 dB / SSIM 0.885；浮世绘 27.20 dB / 0.887；水墨 26.29 dB / 0.890。旧评估器的 `integer_vs_v10` 字段名沿用历史命名，真实参考以报告 `teacher` 路径及 SHA256 为准。相对 QAT 模型自身 FP32 的 SSIM 分别为 0.8435 / 0.8445 / 0.8518。这些是不同参考下的保真诊断，不是官方绝对 PSNR/SSIM 合格线。风格强度仍需同图盲评和硬件实拍验收。

复验命令（从交付目录内的 `StyleCam` 根目录执行）：

```powershell
python -m pip install -r requirements_pc.txt
python -X utf8 tools/check_manifest.py
python -X utf8 tools/verify_delivery.py `
  --workdir C:/fpga_check/v21_pc --gcc C:/mingw64/bin/gcc.exe
```

输出目录必须尚不存在；工具路径按安装位置替换。完整 VGA 和综合命令见硬件组接入说明。早期 `v21b_pc_validation_ncal16/validation.json` 是未完成 VGA 的中间记录，不能替代 `delivery_pc_v21_20261005/verification.json`。

## 边界和下一步

当前包能让硬件组直接取得同一版本的网络 RTL、权重、系数、blob 和固件头，并复现 PC/RTL 对拍；它不能替代完整板级工程。`deployment_status.json` 明确记录：没有完整 StyleCam bitstream/ELF，没有真实 SC431HAI/Ti60 视频，持续板端 FPS、风格切换和 board profile 尚未验收。原厂 `vendor_camera_only_images` 只用于摄像头通路演示，不能与 v21 网络 blob 混烧。

完整包文件由 `sha256_manifest.json` 校验；包内不含虚拟环境、Efinity 工具链或完整训练数据集。v21 训练使用的公开参考图和 Skill teacher 子集保留在 `StyleCam/dataset_v2/style_references_expanded_20261005/` 与 `StyleCam/dataset_v2/skill_teacher_expanded_20261005/`。
