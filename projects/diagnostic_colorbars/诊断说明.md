# IMX219 内置彩条诊断版

此目录是从 `E:\FPGA\Ti60f225_imx219hai2hdmi_v7` 复制的独立工程。商家原工程和原 bit 文件未修改。

## 改动

- 相机初始化表末尾增加测试图窗口尺寸：`0x0624/25 = 1920`、`0x0626/27 = 1080`。
- 设置 `0x0600/01 = 0x0002`，启用 IMX219 内置彩条。测试图由传感器产生，不经过镜头成像。
- 初始化表长度由 61 增至 67。
- 关闭工程 XML 中的调试器自动插入，以绕开此商家工程在 Efinity 命令行中缺少 `work_dbg/debug_top.v` 的构建问题；原有视频 RTL 未改变。

## 编译结果

Efinity 2026.1 的 map、place-and-route、Interface Designer、bitstream generation 均完成。输出：`outflow/ti60f225_oob.bit`。尚未在开发板上验证。

## 测试与判断

保持摄像头接在已能出画面的 U1，先断电确认排线连接，再上电。用 Programmer 选择本目录的 `outflow/ti60f225_oob.bit`，以 JTAG 方式配置 FPGA。彩条不应随镜头所拍物体变化。

- 彩条亮度和颜色基本正常：继续检查实际曝光、增益写入与镜头/传感器成像。
- 彩条出现但仍偏绿、偏暗：继续检查 RAW10 解包、拜耳排列和 RGB 后处理。
- 仍是实时画面：先核对是否烧录了本目录 bit，再核对新增 I2C 寄存器是否写入成功。
- 无画面或花屏：记录 LED 和显示现象，先用商家原 bit 恢复基线。

测试后可重新烧录商家原始 `E:\FPGA\Ti60f225_imx219hai2hdmi_v7\outflow\ti60f225_oob.bit` 恢复实时画面。
