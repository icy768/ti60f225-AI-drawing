# SC431HAI 室内实景暗部提亮对照

本工程从官方 `Ti60f225_sc431hai2hdmi_v6` 复制，原工程和原 bitstream 未修改。它用较短曝光、中等增益与显示端反向 gamma 曲线，比较室内暗部和高光细节。

## 改动

- `rtl/cam_i2c_ctrl/i2c/i2c_master_reg_rom.v`：帧长设为 1500 行（`0x320e/f = 0x05dc`），曝光设为有效上限附近的 2989 半行（`0x3e00/01/02 = 0x00/0xba/0xd0`）；模拟增益约 4.043 倍（`0x3e08/09 = 0x81/0x2a`）；写入 `0x4501 = 0xa4` 明确关闭内部渐变。
- `rtl/cam_i2c_ctrl/i2c/i2c_master_ctrl_top.v`：初始化项数从 164 增为 167。
- `ti60f225_oob.xml`：关闭自动插入调试逻辑分析器，解决本机编译时的调试插入错误；相机接收与 HDMI 主链路不变。
- `rtl/gamma_conrrection/inv2p2.mem`：增加 10 位反向 gamma 2.2 查找表，主要提亮中暗部，纯白保持纯白。
- `rtl/ti60f225_oob_top.v`：固定启用该 gamma 输出，红、绿、蓝分别接回对应 HDMI 通道。原例程中的红蓝在 gamma 关闭分支相互交换。

## 下载和观察

使用 Efinity Programmer 的 **JTAG** 模式下载 `outflow/sc431hai_tonemap_v6.bit`。JTAG 下载只配置 FPGA 的易失性逻辑，不写板载 Flash。断电重新上电会恢复 Flash 中原有工程。

预期画面：显示随镜头移动的彩色实景。与 8 倍模拟增益版相比，亮处纸张的文字不应被大面积冲成纯白，同时暗处有一定可见度。反向 gamma 不能恢复传感器已饱和的细节，也不能纠正镜头失焦。

本机 Efinity 2026.1 的 map、interface、pnr、pgm 均通过；已通过 JTAG 下载至 Device ID `0x10660A79`。

## 现场对照结果

- 约 8 倍模拟增益版使室内明显变亮，但亮处更容易过曝。
- 本版的亮处和暗处均比上述版本改善；在约 2 米远景中，整体仍偏发白，细节偏软。
- 保持同一传感器设置、只把反向 gamma 降至 1.5 后，用户反馈暗处明显更难看清，整体不如本版，因此已通过 JTAG 恢复本版。
- 原始灰度实景与彩色实景均出现相近模糊；此结果尚不足以判定镜头、对焦距离或传感器采样链路的具体原因。
