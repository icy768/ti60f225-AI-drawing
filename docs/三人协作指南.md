# 三人协作

工程统一在 FPGAProjects：StyleCam_camera 是当前完整整机，StyleCam 是 V21b 算法网络，sc431hai_hdmi 是独立摄像头基线。

- A：摄像头、CSI、DDR、HDMI、约束和 FPGA 顶层。
- B：模型、量化、网络 RTL/权重和整数对拍。
- C：固件、BSP、接口和整机集成。

main 保存已验收的 SCU09 / V21b 整机，develop 用于后续集成；本次发布后两个长期分支同步。后续从最新 develop 建短期分支，经 PR 审查后合入 develop，验收后发布至 main。
不在共享分支强推，不整目录覆盖队友文件。

## 日常操作

在本地仓库根目录执行：

```powershell
git fetch origin --prune
git switch develop
git pull --ff-only origin develop
git switch -c fpga/功能名
# 算法负责人用 ai/...；固件负责人用 fw/...
git add FPGAProjects/本次修改文件
git diff --cached
git commit -m "说明具体修改"
git push -u origin HEAD
```

PR 写清修改、验证命令、结果和未验证范围。模型更新必须成套提交 checkpoint、qparams、生成 RTL/mem/blob 和相关 IN/固件参数。
当前摄像头整机使用 1920×1080 RAW10，中央裁剪至 1280×960 后得到 640×480 RGB；这条整机架构是全 RTL，无需 CPU/ELF。
StyleCam 内的 vision_map.xml 为算法交付子系统入口；实际整机使用 StyleCam_camera/ti60f225_oob.xml。
