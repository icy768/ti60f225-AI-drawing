## 下一步所需资料与工作

1. 向相机商家取得**实际模组的 PCB 型号或原理图、22 Pin 接口逐脚定义、15→22 Pin 排线连通表**，确认 Pin 1 和触点方向。
2. 确认模组输入电压、板载稳压、I²C 电平与上拉、24 MHz 参考时钟来源、复位/使能脚定义；与 Ti60F225 主板目标接口逐脚核对，确定是否需要专用转接板。
3. 接口确认后，在官方视频工程基础上配置 IMX219 的 2-lane CSI RX，接入已写的 I²C 初始化模块，并验证芯片 ID、寄存器配置和 MIPI 有效帧。
4. 完成 RAW10 到 RGB、帧缓存、HDMI 输出集成；先用 IMX219 片内彩条验证整条链路，再切换至实时图像。无有效帧时应输出明确的黑屏或测试图，不应显示未初始化的帧缓存内容。

交接时请区分：**LED 与 HDMI 彩条已跑通；IMX219 只有控制代码通过综合，接口和完整视频例程仍待完成。**
