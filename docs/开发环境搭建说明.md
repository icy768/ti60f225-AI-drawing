# 易灵思 Ti60F225 赛题一：开发环境搭建

本说明以本目录中的第三方 `Ti60F225 DemoBoard v4` 和官方提供的
`SC431HAI → HDMI` 例程为准。目标是在**不改动官方例程**的前提下，先完成
“打开工程、下载既有 bitstream、编译工程、串口观察”的最小闭环。

## 1. 已确认的环境基线

| 项目 | 本赛题采用的基线 |
| --- | --- |
| FPGA | Efinix Titanium Ti60F225（工程器件名：`Ti60F225`） |
| 开发板 | `Ti60F225_DemoBoard_v4`（需以实际板卡丝印为最终准） |
| 摄像头链路 | SC431HAI，MIPI CSI-2 输入 |
| 显示输出 | HDMI |
| 主例程 | `官方资料/.../10_Ti60f225_sc431hai2hdmi_demo/Ti60f225_sc431hai2hdmi_v1` |
| Efinity 版本 | **2025.2.288（或该版本的官方补丁）** |
| 主机系统 | Windows 10/11 64 位 |

主例程的工程文件 `ti60f225_oob.xml` 记录的版本是 `2025.2.288.3.8`。不要一开始
直接用当前最新版本重建工程：新版可能会触发 IP 升级、约束迁移或时序结果变化。待官方例程
在 2025.2 稳定跑通后，再单独复制工程测试升级。

## 2. 需要安装的软件

1. **Efinity IDE 2025.2.288（Windows x64）**：综合、布局布线、bitstream、下载器、
   Interface Designer、IP Manager 和 Debugger。
2. **对应版本的 Efinity RISC-V Embedded Software IDE**：后续给 Sapphire RISC-V
   编译 C 程序时使用；仅跑第一阶段 HDL/视频例程可暂缓。
3. **下载器 USB 驱动**：板卡资料自带，目录为
   `官方资料/Ti60F225_DemoBoard_v4完整资料包/Ti60F225_DemoBoard_v4/驱动安装及说明`。
4. **JRE 8 x64（可选）**：仅当旧版 Eclipse/RISC-V IDE 安装器提示缺少 Java 时安装。
   离线安装包位于 `软件安装包/jre-8u381-windows-x64.exe`。
5. **VS Code（已安装）**：仅用于编辑 Verilog、C、Python 与查看日志；它不替代 Efinity。

Efinity 和 RISC-V IDE 均从 Efinix Support Center 下载。注册账号后请求免费的软件许可证，
并把许可证文件保存在个人目录中；不要把许可证提交到本项目或聊天记录。

## 3. 安装步骤

### 3.1 安装 Efinity

1. 登录 Efinix Support Center，申请 license，并下载 **Efinity 2025.2.288 Windows x64**
   安装包及该版本可用的 patch（若有）。
2. 右键安装包，选择“以管理员身份运行”；推荐安装到默认的
   `C:\Efinity\2025.2`（路径避免中文、空格和过深目录）。
3. 首次启动 Efinity 时按提示导入或指定 license。确认项目窗口能够新建 Titanium 工程。
4. 如果下载了 patch：先安装基础版；打开普通命令提示符，执行

   ```bat
   C:\Efinity\2025.2\bin\setup.bat
   ```

   再在解压后的 patch 目录运行 `run.bat`。patch 的目标安装目录必须是上一步的 Efinity 目录。

5. 打开“About”确认版本为 `2025.2.288`，随后关闭软件再继续下一节。

### 3.2 安装下载器驱动

1. 板卡断电，先连接其下载口到电脑 USB（不要把摄像头或 HDMI 热插拔当作下载口）。
2. 在“设备管理器”查看新增设备。若设备带黄色叹号，进入资料中的“驱动安装及说明”目录，
   对与实际枚举设备匹配的 `.inf` 文件右键选择“安装”。
3. 若资料明确要求使用 Zadig，再运行目录中的 `zadig-2.8.exe`，只给**下载器对应的 USB
   设备**绑定 `libusbK`；不要对键盘、鼠标、U 盘等任意其他设备操作。
4. 重新插拔下载线，在 Efinity Programmer 中点击扫描；能显示 JTAG 器件链才算驱动成功。

### 3.3 安装 RISC-V IDE（第二阶段前完成）

安装与 Efinity 同代的 RISC-V Embedded Software IDE，推荐目录：
`C:\Efinity\efinity-riscv-ide-2025.2`。首次启动时把 workspace 放在短英文路径，例如
`C:\fpga-work\riscv-workspace`，避免 Eclipse 对中文和超长路径的兼容问题。

## 4. 首次工程验证（按此顺序）

### A. LED/按键：验证下载链路

先打开：

`官方资料/Ti60F225_DemoBoard_v4完整资料包/Ti60F225_DemoBoard_v4/01_Ti60F225_Key_led_osc_demo/01_Ti60F225_key_demo/LED_8bit_Test.xml`

在 Efinity 中选择 **Run → Compile**。成功后，在工程 `outflow` 目录选生成的 `.hex` 或 `.bin`
到 Programmer 下载。确认按键和 LED 响应。这一步不涉及摄像头，失败时只检查供电、JTAG、驱动、
下载模式和板卡版本。

### B. HDMI：验证视频输出

再打开 HDMI 彩条例程，确认显示器能锁定分辨率并显示画面。HDMI 不出图时，优先检查显示器、
HDMI 线和板卡跳帽，**不要**先改 TMDS/PLL 源码。

### C. SC431HAI → HDMI：赛题视频基线

打开以下 Efinity 工程文件：

`官方资料/Ti60F225_DemoBoard_v4完整资料包/Ti60F225_DemoBoard_v4/10_Ti60f225_sc431hai2hdmi_demo/Ti60f225_sc431hai2hdmi_v1/ti60f225_oob.xml`

该工程已经包含以下模块，后续只在它的副本上开发：

`SC431HAI I2C 配置 → MIPI CSI-2 RX → Debayer → DDR3 帧缓存 → HDMI TX`

首次不要编译，先在 `outflow/ti60f225_oob.hex` 选择 **SPI Active**，起始地址设为
`0x000000`，下载既有 bitstream，以缩短定位时间。能看到实时画面后，才点击 Compile。

> 说明：`SPI Active` 会写入板载 Flash，掉电后仍保留；日常调试优先选择临时 JTAG/SRAM
> 模式（取决于本板卡下载器界面），避免反复擦写 Flash。只有需要上电自启动时才写 SPI Flash。

## 5. 编译完成的判据

在 Efinity Dashboard 中依次应为绿色通过：Synthesis、Place & Route、Timing Analysis、
Bitstream Generation。随后检查：

- `outflow/ti60f225_oob.hex` 的修改时间晚于编译开始时间；
- `outflow/ti60f225_oob.timing.rpt` 中没有未约束时钟或 timing failure；
- Programmer 能识别目标器件并完成下载；
- 串口日志（若例程启用）没有持续复位；
- 显示器稳定显示摄像头画面至少 5 分钟。

禁止只看到“生成了 hex”就认定编译可用；时序失败的 bitstream 不作为开发基线。

## 6. 推荐的工作目录和协作规则

不要直接修改 `官方资料`。首次验证成功后，复制主例程到：

```text
工程/
  video_baseline/       # 官方 SC431HAI-HDMI 工程的只读基线副本
  style_renderer/       # 本队后续改造工程
模型/
软件/
文档/
```

每次修改前在 Git 中提交一个可上板版本，并在提交说明中记录：Efinity 版本、板卡版本、摄像头、
输出分辨率、是否通过 timing、bitstream 文件名。不要提交 `outflow` 的大体积中间文件、license、
个人 IDE workspace 或视频素材。

## 7. 常见故障快速定位

| 现象 | 首先检查 | 暂不应做的事 |
| --- | --- | --- |
| Programmer 无 JTAG 器件 | USB 线、驱动、供电、下载口 | 修改 HDL |
| LED 例程能下载，HDMI 黑屏 | 显示器/线材/跳帽/输出分辨率 | 修改 MIPI 模块 |
| HDMI 有彩条，无摄像头画面 | 摄像头排线方向、供电、SC431HAI 适配版本、I2C 配置 | 自己重写 CSI-2 |
| 编译失败且提示 IP 版本 | Efinity 是否为 2025.2、工程是否被自动升级 | 强行忽略 IP 升级提示 |
| 编译通过但 timing fail | 查看时钟约束和时序报告 | 直接烧录作为基线 |

## 8. 本阶段交付门槛

完成以下四项后，才进入 RAW/RGB、卷积和模型工作：

1. Efinity 2025.2 与 license 可正常启动；
2. Programmer 能识别开发板；
3. LED/按键例程已上板；
4. SC431HAI → HDMI 官方 bitstream 已稳定显示，并且该工程重新编译通过 timing。
